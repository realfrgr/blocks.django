Blocks — Веб-платформа для игрового сообщества

Авторы: Квашнин Борис, Жарков Даниил
Проект для: Открытой городской научно-практической конференции «Инженеры будущего» (г. Москва)
Секция: Веб-сайты и веб-приложения

Описание проекта

Blocks — это разработанная с нуля веб-платформа для геймеров, предоставляющая единое пространство для публикации новостей, обмена видео-спидранами и организации турниров. Проект представляет собой полноценное веб-приложение с серверной логикой, базой данных и пользовательским интерфейсом.

Ключевые особенности (реализовано)

✅ Полная разработка с нуля — весь код написан самостоятельно
✅ Три основных модуля:

· Система публикации и отображения игровых новостей
· Каталог видео-спидранов с метаданными
· Платформа для создания и управления турнирами

✅ Современный технологический стек:

· Backend: Python 3 + Django 4 (чистая архитектура MVC)
· База данных: SQLite с ORM Django
· Frontend: HTML5, CSS3, JavaScript
· Контроль версий: Git + GitHub

✅ Полностью работоспособный прототип:

· Запускается локально на встроенном сервере Django
· Имеет административную панель для управления контентом
· Демонстрирует все основные функции платформы

Структура проекта

blocks.django/

└── reqs.txt          # Список всех зависимостей
Быстрый запуск (для демонстрации)

1. Клонируйте репозиторий:

git clone https://github.com/realfrgr/blocks.django.git
cd blocks.django
1. Установите зависимости:

pip install -r reqs.txt
1. Запустите сервер:

python manage.py runserver
1. Откройте в браузере:

· Сайт: http://127.0.0.1:8000/
· Админ-панель: http://127.0.0.1:8000/admin/
